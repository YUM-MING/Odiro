## 공통 규칙

- **브랜치**: 별도 브랜치 없이 **`main` 에 바로 커밋·push** 한다 (주 1명 담당이라 충돌 없음). push 하면 자동 배포가 돈다(약 12분). push 전에 `pytest`, `ruff check odiro tests scripts`, 프론트 `npm run lint && npm run build` 통과를 확인한다. 문서만 고칠 때는 모아서 push.
- **커밋 메시지**: 한국어 OK, 첫 줄에 뭘 했는지. 예: `Tool: get_route 구현 + 직선거리 폴백`
- **키·데이터 절대 커밋 금지**: `.env`, `data/raw`, `data/vectorstore`, `cache` 는 이미 gitignore.
- **비용이 드는 변경은 금액부터**: Cloud Run 설정, 대량 라벨링·임베딩처럼 과금이 바뀌는 일은 예상 금액을 팀 채팅에 먼저 적는다.
- **막히면**: 하루 이상 막히는 건 팀 채팅에 바로 공유. API 승인 지연은 담당자가 아닌 사람도 신청 가능.
- **주 마지막 날**: `docs/HANDOVER.md` 맨 위에 본인 섹션을 추가하고 push 한 뒤 다음 담당자에게 알림.
